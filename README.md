# Archiana Company Profile — Next.js + TypeScript + Tailwind CSS v4

Basic slicing starter based on the Archiana Figma direction.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Structure

- `src/app` — Next.js App Router
- `src/components/layout` — Navbar and Footer
- `src/components/sections` — Hero, Projects, About, Services, CTA
- `src/components/ui` — reusable CTA button
- `public/images` — visual assets

## Tailwind v4

Tailwind is configured through CSS-first `@import "tailwindcss"` and `@theme` tokens in `src/app/globals.css`.
